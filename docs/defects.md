# 预置缺陷清单（标准答案）

靶机故意埋入 6 个缺陷。检出率以这份清单为唯一口径，不事后修改。

| # | 接口 | 类型 | 触发条件 | 预期检出用例 |
|---|------|------|----------|--------------|
| D1 | GET /admin/users | 未鉴权访问 | 不带 token 直接请求 | 安全：未鉴权访问应被拒绝 |
| D2 | GET /users/{user_id} | 越权 IDOR | 用 alice 的 token 查 bob 的 id | 安全：越权查询应被拒绝 |
| D3 | POST /orders | 参数校验缺失 | quantity 传 0 或负数 | 安全/异常：应返回 4xx，实际返回 500 |
| D4 | GET /search | 注入模拟 | q 含 `' OR '1'='1` | 安全：不应返回全量用户数据 |
| D5 | GET /slow-report | 慢接口 | 正常请求 | 性能：响应时间超过 1s 阈值 |
| D6 | POST /chat | 提示注入未拦截 | message 要求泄露系统提示 | 安全：不应返回系统提示内容 |

说明：D4 的注入只作用于内存假数据，不连接真实数据库。
